# Master Agent Capabilities & Web Design Directives

This project implements the comprehensive standard for **UI/UX Pro Max**, **Frontend Design Skill**, **Vanilla Evergreen Web Craft**, **SEO Optimization**, and **Core Web Vitals Performance**.

### Key Rules Enforced:
1. **Zero-Maintenance / Evergreen Execution**: When Vanilla HTML/CSS/JS is requested, write standard W3C-compliant semantic code with zero third-party runtime dependencies.
2. **Design Intelligence**: Mathematical padding, nested border radius calculations, WCAG AA color contrast, fluid `clamp()` typography, and zero generic AI cliches.
3. **Hardware-Accelerated Interactions**: Native `IntersectionObserver` scroll reveals, `<dialog>` modals, smooth transitions, and high performance.
